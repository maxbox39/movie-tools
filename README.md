# movie-tools

Плагін для [Lampa](https://github.com/yumata/lampa-source): **інструменти для фільмів** — бейджі, пріоритети, колекції, жанри, фільтри та сортування.

![Lampa](https://img.shields.io/badge/Lampa-plugin-blue)
![TMDB](https://img.shields.io/badge/data-TMDB-01b4e4)
![License](https://img.shields.io/badge/license-MIT-green)

---

## Встановлення

1. У Lampa відкрий **Налаштування → Розширення / Плагіни**.
2. Додай плагін:
https://maxbox39.github.io/movie-tools/movie-tools.js

3. Перезапусти Lampa.

## Можливості

### Бейджі на картках

| Бейдж | Місце | Опис |
|--------|--------|------|
| **Рейтинг** | правий верх | колір за оцінкою TMDB |
| **Тривалість** | правий низ | наприклад `1г 48хв` |
| **Пріоритет** | лівий верх | 🔥 / ⭐ / ⏳ |
| **Улюблений жанр** | лівий низ | 👍 |

**Колір рейтингу**
- 🟢 високий (за замовчуванням ≥ 7.5)
- 🟡 середній (≥ 6.0)
- 🔴 низький
- ⚪ сірий — якщо мало голосів (поріг налаштовується)

### Сторінка фільму

- Кнопка **«Пріоритет»** — високий / хочу подивитись / пізніше / скинути  
- Кнопка **«Колекція»** — список частин франшизи з TMDB (наприклад Spider-Man, Посіпаки)

### Фільтри

- За тривалістю: до 100 хв / 100–140 хв / 140+ хв  

### Сортування

- За роком (↑ / ↓)  
- За рейтингом (↑ / ↓)  
- За тривалістю (↓)  

### Улюблені жанри

- Вибір жанрів у налаштуваннях  
- На картках з’являється значок **👍**

## Налаштування

**Налаштування → Фільми (tools)**

| Параметр | Опис |
|----------|------|
| Бейдж рейтингу | Увімкнути / вимкнути |
| Бейдж тривалості | Увімкнути / вимкнути |
| Бейдж пріоритету | Увімкнути / вимкнути |
| Мін. голосів для кольору | Поріг `vote_count` |
| Фільтр за тривалістю | Ховати фільми поза діапазоном |
| Сортування | Порядок карток у списках |
| Улюблені жанри | Список жанрів для 👍 |
| Показувати лайк для улюблених жанрів | Увімкнути / вимкнути 👍 |
| Скинути всі пріоритети | Очистити 🔥⭐⏳ |

## Сумісність

- Lampa з `SettingsApi`, `Select`, `Activity`, `Controller`
- Пульт TV: кнопки на full-картці в навігації, фокус після меню не губляється

---

## Примітки

- Працює **тільки для фільмів** (серіали ігноруються)
- Тривалість і колекція залежать від даних TMDB
- Після зміни фільтра/сортування оновіть список (вийти й зайти знову)
